# Coorg Pantry System

## 📌 Project Overview
Coorg Pantry System is a full-stack web application developed to manage pantry products and inventory efficiently. The system allows users to add, update, delete, and monitor products through a responsive and user-friendly interface.

---

# 🚀 Features
- Product Management
- Inventory Tracking
- Add/Edit/Delete Products
- Responsive User Interface
- Backend API Integration
- Database Connectivity
- Real-Time Data Management

---

# 🛠️ Technologies Used

## Frontend
- React.js
- HTML5
- CSS3
- JavaScript

## Backend
- Node.js
- Express.js

## Database
- MongoDB

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/REPOSITORY_NAME.git
```

---

## 2️⃣ Open Project Folder

```bash
cd Coorg-Pantry-System
```

---

# ▶️ Backend Setup

## Go to Backend Folder

```bash
cd product-backend
```

## Install Dependencies

```bash
npm install
```

## Start Backend Server

```bash
npm start
```

Server runs on:

```bash
http://localhost:5000
```

---

# ▶️ Frontend Setup

## Open New Terminal

```bash
cd project
```

## Install Dependencies

```bash
npm install
```

## Run Frontend

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
